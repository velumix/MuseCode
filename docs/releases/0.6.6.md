# Velum Code 0.6.6

- Automatically check GitHub for new app releases and download signed updates.
- Install a downloaded update with **Settings → Updates → Restart to update**.
  Running conversations and unpaused queues must finish or stop first.
- Warm up provider discovery, show Muse CLI readiness, and label Muse token
  estimates when its CLI does not report a context capacity.
- Bound silent turns and orphaned output pipes, keep completed responses during
  cleanup, and terminate version probes and their descendants on timeout.
- Retry failed provider warmups with Refresh.
