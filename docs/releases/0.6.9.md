# Velum Code 0.6.9

- Check GitHub for app updates at the beginning of the launch animation, before
  loading the workspace, providers or scheduled agent work.
- Show download progress, verify the signed installer, install silently and
  reopen automatically. Saved conversations, drafts and preferences are restored.
- Open the current version if the launch check exceeds eight seconds or an
  update fails. **Open current version** cancels a check or download before
  installation starts.
- Prevent repeated automatic restarts when an installer did not replace the app.
  Retry that release in Settings; newer releases remain eligible.
- Keep six-hour background checks while the app is open. Updates found then
  use **Restart to update**, or install automatically at the next launch.
- Preserve the **Automatic updates** preference, including previous opt-outs.
- Keep the launch branding in place as download and install messages change.
- Close the entire owned browser preview process tree and retry brief Windows
  file locks before deleting its temporary profile.

Installed 0.6.6–0.6.7 copies need **Settings → Updates → Restart to update** once
to install this launch behavior. Later startup updates are automatic.
The 0.6.8 candidate was not published because a hosted browser cleanup check
failed; 0.6.9 includes the cleanup fix.
